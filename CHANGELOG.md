# Changelog

All notable changes. Versions follow [semver](https://semver.org); a release is made for every new `VERSION`.

## v0.1.1 (2026-11-21)

- The live stress line stays within the terminal width: shorter temperature sparkline, only the main throttle
  reason (the full list is in the results). Before, a throttled Pi made the line wrap and every redraw stacked
  a new line.
- README screenshots of both sample machines (`docs/`, regenerated by `tools/screenshots.sh`).

## v0.1.0 (2026-11-21)

First public release: static checks (board, power and thermals, firmware and OS, storage, kernel log, system,
security, network), CPU stress and storage write/read-back tests, JSON and Markdown reports, fake machines
for tests, release binaries for arm64, armv7 and armv6.
